# Sources and attribution

The site uses React, TypeScript and Vite with native CSS and existing JavaScript animation controllers. Component source references and available licenses are retained in `component-sources/`; these are provenance, not loaded site files.

- Player photograph: user-supplied reference, stored unchanged as `experience/reference-turntable.png`. HTML overlays replace the label and animate the record/needle. No third-party image license is claimed.
- Faceted heart and wood grain: local SVG assets retained because active HTML/CSS references them.
- Golos Text: locally hosted fonts in `assets/`; SIL OFL in `assets/OFL.txt`.
- Lightning: David Haz / React Bits ElectricBorder; runtime adaptation in `experience/trail.js` and `experience/vendor/trail-shader.js`. Original ElectricBorder and React Bits license retained. https://github.com/DavidHDev/react-bits
- Audio: Linkin Park — What I've Done, Apple Music preview streamed after interaction. The decorative record label is the portfolio identity, not song attribution. https://music.apple.com/us/album/what-ive-done/590427297?i=590427450
- Navigation: native adaptations referencing Aceternity tabs, Arc Library tabs, and Untitled UI tabs/buttons. https://ui.aceternity.com/components/tabs ; https://github.com/kuratlielia/arc-library ; https://github.com/untitleduico/react
- Contacts: Magic UI Morphing Text adaptation. https://magicui.design/docs/components/morphing-text
- Skills: Magic UI Bento Grid adaptation. https://magicui.design/docs/components/bento-grid
- Language control: Untitled UI Button Group, with local sliding selection/translation animation.
- Liquid surfaces: user-supplied Nimbus Liquid Glass Navbar/Waterline component, credited in its original source to guglielmogiannattasio.it; native shader/spring adaptation in liquid.js.
- About cards: user-supplied PerspectiveTunnelHero; native one-time reveal and pointer repulsion in about-tunnel.js. Demo photos are not used.
- Name animation: user-supplied murmuration wordmark, native adaptation in name-murmuration.js.

Rejected concepts, candle effects, spinning contact text and editorial typography are no longer included. Reference originals do not imply that all their features are enabled.
